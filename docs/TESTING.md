# 验证策略与证据

## 本仓库现有测试

```bash
./scripts/swift.sh run EDASelfTests
KICAD_CLI=/path/to/kicad-cli python3 scripts/integration-test.py
python3 scripts/check-coverage.py
```

EDASelfTests 不依赖 XCTest。测试路径越界、符号链接、未知格式、拒绝覆盖、快照篡改、生成目录排除、BOM 组键/DNP/重复位号/价格、CSV 转义/公式防护、线束针脚规则、阻抗参考值、S-expression 错误/深度、预览几何、进程大输出/退出码/超时和报告格式。测试失败退出非零。

真实集成测试需要 KiCad 10：复制自包含项目到含中文和空格的路径，运行全部 12 种作业、制造发布和输出哈希核对；删除走线验证拒绝发布、模拟四层板验证不会漏内层、篡改快照验证拒绝。没有引擎时测试失败，不以 mock 假装真实通过。

reports/core-tests.json 与 integration.json 为运行证据；VALIDATION.md 描述平台、范围和剩余限制。零违规 LED 夹具不证明所有电气规则、多层或全部编辑器功能。

## 必需的后续测试层次

1. 单元：模型不变量、规则优先级、单位、网络连通、事务、引用闭包与错误恢复。
2. 黄金设计：层次电路、多单元、总线、2/4/16/32 层、BGA/HDI/差分调谐/刚柔/多板/线束，含明确正常/异常预期。
3. 互操作：独立 Gerber、钻孔、ODB++/IPC-2581/STEP 阅读器和制造合作方核对，不仅检查文件非空。
4. 编辑流程：两架构 Mac、人机操作、跨探测、撤销重做、保存重开、IPC 保存确认。
5. 故障：磁盘满、断电、子进程崩溃、取消、并发外部编辑、库缺失、坏数据、项目路径/编码。
6. 离线：系统封锁网络和抓包，完整从创建到制造/仿真/恢复流程，无在线许可依赖。
7. 性能：记录机型、系统、引擎、库、对象数、内存、P95 耗时、交互帧率，避免只给空项目数据。

## 90% 门禁

类别占比总和固定 100%。implemented/inherited/planned 都不能计入 verified。完整验收记录需 feature ID、平台、程序/引擎版本、夹具哈希、正负预期、独立验证、人工操作记录、结果和审阅批准。每类别 ≥80%、总分 ≥90%，关键 SI/PI/刚柔/多板/线束和单板/制造必须通过，且无未关闭的严重数据或开短路缺陷。

当前 check-coverage 输出 0% 是“完整验收分数尚未建立”，不代表程序不可运行或 KiCad 没有功能。代码实现与专业验收的区别必须保留。

## CI

基础 CI 编译、运行 EDASelfTests、验证功能数据、构建 app 并保留 artifact。可选人工触发 KiCad 集成工作流下载固定官方包并校验。签名公证与硬件/代工验收不在当前 CI 中。流水线失败不能自动把状态变为通过。
