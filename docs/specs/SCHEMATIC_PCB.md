# 原理图、PCB 与约束规格

状态：单板编辑使用 KiCad；以下专业流程待逐项验收或实现。

## 权威数据与编辑

SchematicDocument 保留符号 UUID、层次页路径、引脚、电气类型、总线/网络名与元件字段。BoardDocument 保留封装 UUID/原理图 path、铜层、焊盘、走线、过孔、区域、叠层和规则。工作台预览只读，不得参与网络抽取；权威网表和 DRC 由引擎提供。

IPC 服务启动时查询能力与主版本，提交事务携带 expectedRevision 和操作列表，成功后要求保存回执、重新读取网表/哈希。多窗口编辑有外部文件变更检测；冲突不以时间戳更近自动取代。

## ECO 流程

原理图修改 → 网表/封装映射提取 → 新增/删除/改值/改封装/改网的差异预览 → 用户批准 → 引擎提交 → ERC/DRC/一致性检查 → 保存新 revision。删除元件不能悄悄留下无主铜；换封装必须审查焊盘映射和三维高度。

## 约束模型

ConstraintSet：网络类、对象选择器、区域、适用层、优先级、值及单位。规则冲突采用确定性顺序：显式对象规则 > 区域规则 > 网络类 > 全局默认；未实现前使用原生引擎规则。每个对象可查询规则命中的解释。

包含线宽、铜距、孔径/环宽、层对、差分间距/偏差、线长、延时组、禁布/禁高、阻焊/钢网。延时不是简单几何长度，需要介质、层叠、过孔和求解模型；无法评估时报告 unsupported，禁止推断通过。

## 多层制造

导出时从板配置枚举所有启用的铜层和工艺层，核对 Gerber 数量/层名、钻孔层对和叠层声明。盲埋/微孔记录压合组；板形、槽孔、工艺边进入文档。v0.1 只允许 F.Cu/B.Cu，四层以上必须在原生 KiCad 审核导出，直到多层漏层负测试通过。

## 专业验收

层次/总线/多单元黄金网表；BGA 推挤和撤销；差分过孔、蛇形线长/延时；HDI 层对；覆铜热连接与孤岛；4/16/32 层制造包；10 万焊盘性能；跨探测和编辑器保存回执。文件可读、图形漂亮或单板零违规都不足以完成这些验收。
