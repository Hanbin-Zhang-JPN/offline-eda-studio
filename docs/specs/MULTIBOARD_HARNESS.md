# 多板系统与线束

状态：v0.1 有独立点对点数据、检查和裁线 CSV，没有多板 3D 和线束图形编辑。

## 系统数据

SystemProject 包含 BoardInstances、Ports、Interconnects 和 Assembly。每个端口绑定板实例 ID、元件 UUID、针脚映射、信号类型、电压/电流等级及匹配接插件；跨板重复位号用 BoardID:Reference 区分。网络名相同不自动意味着系统连通。

连接类型：直接板对板、线缆、线束、柔性连接；都须有针脚对照和电气类型检查。板接口 ECO 改动触发相关线束/系统连接过期，制造发布需重新审核。

## 线束专业模型

Connector 的引脚、壳体、端子和防呆方向；Wire 的线径、绝缘、颜色、长度和公差；Splice 作为显式分支节点；Shield、TwistedPair、Sleeve、Branch 与 TerminalCrimp 独立对象。导线长度分开路由几何长度、加工余量和裁线长度，计算规则可审查。

v1 的重复占针拒绝用于点对点；未来支持分支必须通过 Splice，不直接放开唯一性规则。检查包含未知端点、引脚越界、自连接、错误网、端子兼容、接插件性别/方向、额定电压电流、线径与压接范围、屏蔽接地及分支连接。

## 图形编辑与文档

2D 系统连接/线束路由编辑支持选择、吸附、弯折/分支、撤销事务、端口高亮和电气问题定位。制造图提供端面朝向、线色/针脚/端子、套管、长度公差、压接和治具资料；裁线 CSV 只是其中一项。

## ECO

板连接器改变 → 系统端口差异 → 线束受影响对象 → 可审查修复映射 → 系统/板/线束统一批准 revision。不能仅按名字猜测针脚；未分配针脚与错配作为阻塞问题。

## 验收

直连/交叉针脚、重复板、错误性别、越界、线径压接、分支/屏蔽/绞对、线长/余量、接口版本冲突、BOM 聚合、3D 端口映射与制造图核对。当前演示 J2 是外部连接器，数据尚未自动与 PCB 原理图同步。
