# 分阶段路线图与交付门禁

本路线图是工程估算和工作分解，不是已排期或已承诺进度。达到专业 EDA 的 90% 需要持续开发、硬件验收和制造合作方验证；一个短期原型无法证明这一指标。

|阶段|成果|依赖|退出条件|
|---|---|---|---|
|P0 基础工作台|SwiftUI、CLI、离线数据、示例、快照、双层发布、CI|macOS 工具链与 KiCad 10|核心正负测试/真实导出通过；已交付 v0.1，完整 UI 与断网验收仍待扩大|
|P1 单板闭环|原生编辑流程、约束管理、多层完整出图、全部制造输出与图纸|P0|2/4/16/32 层夹具、层次电路与原理图一致性、独立制造文件复核|
|P2 数据与生产管理|受管库、依赖闭包、装配变体、语义快照差异、BOM/审批|P1|清洁 Mac 断网打开工程；变体所有输出一致；崩溃/磁盘满保全|
|P3 高速与机电|二维场求解、SI/PI、MCAD 交换/碰撞、仿真任务图|P1/P2|黄金模型误差达标，收敛与边界条件存档，独立软件互操作|

|P5 达标发布|全部关键功能、性能、无网络、两架构、签名公证与资料|P1–P4|矩阵 ≥90%、每类 ≥80%、关键能力全部通过、无严重数据/电气缺陷|

## 推荐团队能力（估算）

需要 EDA 核心/布线约束、macOS 客户端、几何与机械、SI/PI 数值分析、库/数据/制造、测试与发布等能力。采用成熟引擎的前提下，可按约 6–10 人、18–30 个月规划初始预算，再用 P1/P2 的实测吞吐重新估算；这不是对 90% 的保证。若完全自研原理图、布线和仿真内核，范围与成本会显著增加，需重新做路线图。

## 可直接开工的后续任务

1. 为所有原生 KiCad 功能建立可复验黄金项目，完成 macOS 编辑器人工流程验证，不把上游宣称直接计分。
2. 多层板导出读取已启用 copper layer 集合，核对 Gerber/钻孔/叠层，取消 v0.1 的双层限制前必须通过漏层负测试。
3. 依赖扫描：原理图 lib_symbols、fp-lib-table/sym-lib-table、`${KIPRJMOD}`、KiCad 环境变量、模型相对路径与 SPICE includes，形成锁文件。
4. 把采购计划、设计 BOM、正式装配变体三个概念统一到可审查映射，不静默同步。
5. 把库字段/实例/网络/几何抽取成稳定语义差异，而不是文本 diff。
6. IPC API 连接与版本协商；用户授权的改动要有命令事务、回滚和保存确认。
7. 几何与求解器先建立可独立验证命令行适配，再集成 UI。

## 禁止提前通过的门禁

不因 UI 完成而通过电气功能；不因模型字段存在而通过刚柔/线束；不因 STEP 成功导出而通过机电同步；不因 CSV 能生成而通过 ActiveBOM 等效；不把离线供应链快照当实时数据；不因单个示例零违规而通过全部规则。

迭代结束需更新变更日志、未完成项、夹具版本和证据。只修改矩阵 status 不构成通过验收。
