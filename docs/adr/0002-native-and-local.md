# ADR 0002：原生客户端与开放本地数据

状态：接受。

采用 SwiftUI/AppKit，macOS 14+，无 JavaScript 运行时、HTTP 后端和云账号。项目目录用户可读，KiCad 文件权威，JSON 元数据可审查，未来 SQLite 仅作索引与事务数据。文件输出和快照支持无网络。

SwiftPM 不拉取第三方依赖，示例与文档打入 app。跨平台 GUI 可后续实现，不以削弱 Mac 离线与本地体验为前提。核心业务服务与 UI 分离，CLI 共用相同门禁。

取舍：最低系统 14、当前主机架构构建；Intel/最低系统需要额外测试。未来 App Sandbox 和插件权限隔离需要设计，当前不是沙箱发行版。
