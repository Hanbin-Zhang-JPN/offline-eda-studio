# Altium Designer 功能对标与验收矩阵

基线：2026-10-03 阅读的官方功能资料；不是 Altium 官方的全量功能目录或等效认证。

**目标 ≥90%，当前尚未达成。** status 为 implemented 表示已有代码；inherited 表示引擎拥有相关能力但没有完成本仓库验收；planned 表示只有规格。只有 verified 状态且证据包含版本、平台、正常/异常夹具、人工验证与可复现结果时，才计入验收覆盖率。单个 LED 示例通过不代表完整生产级能力通过。当前所有功能仍待完整验收，因此验收分数为 0%，这不代表引擎没有功能。

## 计算方法

每个类别内按 weight 加权，再按类别占比汇总。分母冻结，不移除难题或把云能力悄悄排除。支持的离线等效流程需单独验收，不能称实时服务等效。

`总分 = Σ 类别占比 × Σ(功能权重 × verified) / Σ(功能权重)`

发布“达到 90%”还必须：每一类别 ≥80%；原理图、PCB、制造、库管理、SI/PI、刚柔结合、多板/线束全部通过关键功能；断网从编辑到制造全流程、资料往返一致性与独立 DFM 验证通过；没有数据损坏、开短路、单位/坐标错位的 P0/P1 缺陷。用户认可该分母后才可用于产品宣称。90% 不是界面相似度、代码行数或按钮数量。
