# 产品需求与边界

## 产品目标

为 MacBook 提供无需联网、账号或激活的电子产品设计工作流。从捕获电路、元件选择、多层 PCB、布线、验证、3D、装配变体、制造文档到本地版本审阅保持数据可追溯。KiCad 原生文件为单板设计权威数据，工作台不能通过自建简化格式取代电气设计。

“Altium 90%”的分母由 FEATURE_MATRIX 冻结，须由需求方认可。只对具有完整验收证据的功能计分；简单子功能数量不能冲抵复杂能力。12 类均须达到最低分数，关键高阶能力须全部通过。v0.1 当前不做达标宣称。

## 用户场景

1. 普通硬件工程师：带着已准备好的库断网，在 Mac 创建原理图、布线并交付双层/多层板。
2. 高速工程师：层叠、阻抗、差分/延时组约束、仿真证据与走线对应；不把近似计算器当场求解器。
3. 机电工程师：壳体与板框交换、装配位置变更、碰撞/干涉检查和批准事务。
4. 小型团队：本地库批准、设计快照、语义比较、评论、审批，网络同步是可选显式动作。
5. 制造工程师：读取制造网表、所有层、孔表、坐标、BOM、装配变体与可验证的交付清单。

## 当前范围（v0.1）

本地工作台、两层自包含示例、采购计划、点对点线束、不可变快照、KiCad CLI 适配和检查门禁。原生编辑发生在外部 KiCad 应用中；用户保存后刷新。单项作业输出、正式发布目录和失败诊断目录具有不同语义。

## 目标范围（待实现）

四层以上制造流水线、完整依赖锁定/迁移、正式装配变体、受管库、IPC 编辑事务、约束管理、多板装配、刚柔区域和折叠、线束图形编辑、SI/PI 求解集成、生产文档生成、离线审阅/批准。实时供应链服务不能离线等效，只支持带时间戳的导入镜像。

## 非功能指标（目标，尚未实测验收）

|项目|目标|
|---|---|
|平台|macOS 14+，arm64 和 x86_64 独立验证|
|安装|签名/公证 app；离线完整包有 SHA-256 和 SBOM|
|启动|基准 16 GB M 系列机器，空工作区冷启动 ≤3 秒|
|交互|常规 5000 元件 PCB 交互保持 ≥30 FPS；更大项目提供降级/分页|
|索引|10 万元件搜索 P95 ≤150 ms，事务与索引可重建|
|制造|输出哈希可重复；时间戳或引擎非确定字段明确分离|
|安全|不运行 shell 拼接字符串；越界路径/不受信插件可拒绝|
|网络|断网核心流程全通过，无隐式远程下载/遥测|
|保全|原子保存、快照校验、磁盘满/崩溃/超时测试无设计覆盖|
|可访问性|键盘、VoiceOver、中文/英文、缩放和高对比度|

## 数据所有权

项目为用户可直接读取的目录，元数据 JSON、设计为 KiCad 原生文件、未来索引 SQLite 为可重建副本。禁止强制云格式、暗中更换元件库和自动上传电路。程序不得将“导入成功”表述为“电气等价”，必须输出差异报告。

## 完成判定

完整闭环不是仅有按钮：需要正/负夹具、导出独立验证、断网测试、Mac 两架构安装测试、清洁机器迁移、故障注入与需求签收。详细门禁见 TESTING。未完成項目不能在功能矩阵里标为 verified。
