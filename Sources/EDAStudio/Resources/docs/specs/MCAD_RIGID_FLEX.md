# 三维、机电与刚柔结合

状态：KiCad 提供本地 3D/STEP 导出，工作台可执行 STEP 作业；复杂机电协同与刚柔设计待实现。

## 几何基础

建议独立 OCCT 服务进程，输入为锁定 STEP 模型、板框、叠层、元件变换和公差。统一 mm 与右手坐标系；变换使用明确 4×4 矩阵，所有源坐标转换可追溯。模型缺失显示占位和诊断，不把没有模型的空间当无碰撞。

实体/面选择锚点不能只用导入时的数组下标，需关联设计 UUID 与稳定几何签名。引擎更新后拓扑改变的锚点标记失效。

## 双向 ECO

板框/孔/元件位置 → MCAD → 提案 → 差异预览 → 容差/约束检查 →批准 → 原生设计提交。来自外部机械工具的修改必须携带 revision/模型哈希；PCB 已变化时不直接合并。STEP 交换本身不是实时 CoDesigner 等价能力。

## 刚柔区域模型

Stackup 记录铜/介质/覆盖膜/加强片的材料、厚度、层范围与压合序列；Region 为可验证多边形、子叠层 ID、刚/柔类型和优先级；Bend 包含轴、半径、角度、顺序、适用区域与中性面参数。重叠/嵌套区不能用单一板厚处理。

展开/折叠在固定坐标映射上变换几何，保留元件/铜/孔锚点。通过材料厚度和弯曲半径计算路径，但柔性材料的真实力学可靠性需要工程规则与厂商验证，不由 3D 外观决定。

## 检查

区域无意重叠/未覆盖、层集合冲突、柔区过孔和尖角、弯折区元件/铜规则、折叠实体干涉、最小弯折半径与覆盖膜开口。输出展开轮廓、分区叠层、覆盖膜、加强片和钻孔/压合组，与制造商黄金资料对照。

## 多板装配

每个 board instance 具有 designRevision、变换和连接器锚点；配合约束包括平面、同轴、距离、角度和端口。约束图避免环形过约束，求解失败有解释。装配碰撞与系统连接图同 revision，不可用旧板模型批准新系统。

## 关键验收

STEP 独立导入和单位核对、已知干涉/间隙、模型缺失、PCB 外部编辑冲突；单/多弯折、重叠子叠层、开槽与书本结构、展开恢复、刚柔制造文件。未实现折叠/制造映射前，FLEX 类保持 planned。
