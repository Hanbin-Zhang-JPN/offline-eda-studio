# 制造发布与工程文档

## v0.1 已实现

唯一作业 UUID → 验证引擎 10.x → 复制源并核对前后/目标哈希 → 检查铜层仅双层 → ERC 全启用级别 → DRC 加原理图一致性 → 核对结构化报告为空 → Gerber/Excellon/坐标/设计 BOM/PDF → 可选 STEP → 核对源未改和输出非空 → 输出 SHA-256 清单 → move 成 release。

任一步失败保留 failed 目录和已经完成的命令日志，不能生成 release 目录。所有路径带参数数组传入，空格/中文不触发 shell。发布的 planning-bom.csv 单独命名，避免被当成设计权威 BOM。

注意启用的规则以项目和引擎为准；ignored_checks 列出关闭检查，不保证厂商所有 DFM 要求。真正制造文件审核仍需人工和独立工具。

## 目标专业输出

OutputJobSet 记录输入 revision、variant、stackup、工艺能力、模板、引擎/插件版本、作业依赖和交付件。必须包括所有铜层、板框、孔分组、坐标、极性、BOM、装配图、叠层和工厂参数。IPC-2581/ODB++ 输出经独立导入复核，不以非空作为等效认证。

DocsGenerator 以模板创建制造/装配图：可更新的板视图、剖面、尺寸、公差、孔表、叠层、位号、变体 DNP、材料/工艺备注和修订表。尺寸绑定稳定对象 ID，设计改动后失效锚点报错；不能维持旧尺寸并无提示生成新 PDF。

## 制造门禁扩展

1. 来源闭包和批准库完整。
2. ERC/DRC/PCB-原理图一致性通过，禁用规则/豁免有批准及理由。
3. 变体、BOM、坐标、装配图元件集合一致。
4. 层/钻孔/叠层/单位/原点完整；独立网表比较没有额外开短路。
5. 指定厂商 DFM 能力通过或逐条批准；没有“全部忽略”默认选项。
6. 源/输出/审批/工具全部绑定 releaseHash；验包失败禁止交付。

## 可重复性

输出哈希可能受引擎时间戳、排序、文档元数据影响。将语义几何/网表比较与字节哈希分开，不宣称所有导出 bit-for-bit deterministic。检查缓存必须包含源、库锁、规则和工具哈希。v0.1 不复用检查缓存。
