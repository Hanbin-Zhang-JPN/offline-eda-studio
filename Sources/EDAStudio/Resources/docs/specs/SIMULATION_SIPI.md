# SPICE、阻抗与 SI/PI

状态：SPICE 使用原生 KiCad；工作台仅提供薄导体微带初估。以下数值服务待实现，不能以 UI 或近似公式冒充专业求解器。

## SPICE 流程

模型从项目本地目录加载，递归 `.include/.lib` 的依赖闭包检查。实例引脚与子电路声明映射、单位和温度显式记录。JobSpec 绑定电路 revision、模型哈希、仿真器版本、DC/AC/Transient 参数、扫描条件、收敛选项。结果包含日志、波形单位和收敛状态；不收敛不生成可批准结论。

## 二维场求解

Input：截面几何、导体厚度/粗糙度、介质频率依赖、阻焊、回流平面、差分间距；Output：Z0/Zdiff/Zcommon、有效介电常数、损耗、传播延时和误差估计。适配器记录网格、边界条件和收敛曲线。至少用微带、带状、共面和差分黄金模型与独立基准核对。v0.1 Engineering.microstrip 是薄导体准静态近似，不支持上述复杂输入。

## SI 服务

网络拓扑由权威网表/PCB 抽取，包含走线层、长度、过孔、端接、驱动/接收 IBIS、封装和 S 参数。拓扑预览可审查。输出反射、串扰、眼图、时序与裕量；频率/单位/参考阻抗一致。DDR/SerDes/差分模型建立数值误差预算，结果回写长度/延时约束需用户批准。

## PI 服务

DC 压降需要铜厚、平面连通、过孔电阻、负载和电源边界；AC PDN 需要去耦模型/ESR/ESL、端口和网格。输出压降、电流密度、目标阻抗/谐振和收敛。不存在可靠材料/负载数据时返回 missing-input，不作“通过”判断。

## 性能和安全

独立进程运行求解器，限制内存/线程/超时，支持取消与部分日志，输入无写权限。结果不得修改原生板；建议转换成可审查 ECO。未知插件或许可证缺失应报告 unsupported，不静默切换更弱模型。

## 验收

模型单位/引脚异常、SPICE 收敛失败、网格加密收敛、参考精度、过孔/损耗/介质频散、眼图判定、PDN 场景、断网模型闭包、两架构数值差异、结果可复现和修改源后失效。未经工程专家审阅不能计入 SIM06–10。
