# 受管元件库、采购和装配变体

状态：v0.1 为手工采购计划；专业管理与正式变体待实现。

## 三种对象必须分开

- DesignComponent：原理图/PCB 的权威实例，包含网络、封装和电气属性。
- ProcurementPlan：参考位号、MPN、厂商、离线报价和库存。当前 parts.json 即此对象。
- AssemblyVariant：指定设计 revision 上的 DNP/替代料规则，必须同时作用于坐标、BOM、装配图、3D 与制造文档。

采购计划删除/DNP 不改变原理图。正式变体解析器输出 EffectiveAssembly，并被所有作业共用，不允许每个导出脚本独立解释 DNP。

## 本地受管库（目标）

元件 UUID 的每个批准 revision 绑定符号/封装/模型内容哈希、参数单位、生命周期、来源/许可、数据表和审核记录。草稿可以编辑，批准版本不可原地改变；项目通过锁文件引用 revision。SQLite 搜索索引可重建，资源以内容寻址保存。

参数含数量、单位、容差与比较区间；检索结果区分 unknown 和 zero。批准替代料要满足封装/焊盘映射、额定值、容差、温度和高度约束。MPN 字符串相近不能自动替换。

## 离线报价

QuoteSnapshot：供应商、币种、单位、阶梯数量、包装、最小订购量、库存、采集时间、来源。用户主动导入，显示时效；缺报价不计算为 0 成本。批次计算包含单位数量、损耗和包装取整，公式和币种转换资料可审查。不承诺断网实时 ActiveBOM。

## 必需异常测试

重复位号/跨板 ID、引号和换行字段、同 MPN 不同封装、价格分组、缺币种、替代料针脚错配、DNP 坐标遗漏、多变体导出错用、库锁缺失和批准记录冲突。清洁 Mac 不配置全局库即可重开锁定工程。
