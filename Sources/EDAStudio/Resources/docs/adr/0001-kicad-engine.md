# ADR 0001：采用 KiCad 本地引擎

状态：接受。日期：2026-10-03。

用户需要 MacBook 本地离线的专业 EDA。单独实现原理图、电气网表、推挤布线、规则、覆铜、三维、仿真及制造格式是长期高风险工程；已有原生跨平台引擎可让本仓库将工程资源放在离线数据管理与高级模块。

决定：以 KiCad 10 原生设计文件和本地编辑器为单板核心，SwiftUI 提供 Mac 工作台。通过文档化 CLI/未来 IPC 组合，不将未公开引擎 API 直接嵌入。锁定测试基线 10.0.6，未知主版本拒绝。

后果：v0.1 不拥有内嵌原理图/PCB 编辑器，编辑器是独立窗口；需要提前安装 KiCad；依赖上游兼容性。KiCad 的能力不自动等价于 Altium，刚柔、多板、机电同步和 SI/PI 必须独立实现和验收。矩阵保留这些难项，不能删掉后宣称 90%。

其他选择：全自研内核需重新预算；在浏览器画板无法满足专业约束；云 EDA 不符合离线目标；Wine/Windows 商业程序不是原生 Mac 替代方案。
